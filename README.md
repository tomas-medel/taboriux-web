# Taboriux Landing

Landing page profesional para Taboriux construida con:

- Next.js 14+ (App Router)
- TypeScript
- TailwindCSS

## Ejecutar

```bash
npm install
npm run dev
```

Luego abre `http://localhost:3000`.

## Estructura

- `app/`: layout global y página principal.
- `components/`: secciones desacopladas de la landing.
- `public/logo.png`: logo oficial usado en navbar y footer.
